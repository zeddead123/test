MIDNIGHT ANDROID — СБОРКА APK ЧЕРЕЗ GITHUB ACTIONS
=================================================

Этот проект уже настроен для сборки APK на сервере GitHub.
Android Studio на твоём ПК для сборки НЕ нужна.

КАК СОБРАТЬ APK
---------------
1. Зайди на github.com и создай новый репозиторий.
   Например: midnight-android

2. ВАЖНО: загрузи СОДЕРЖИМОЕ этой папки в корень репозитория.
   В корне GitHub должны быть видны:

   app/
   .github/
   build.gradle
   settings.gradle
   gradle.properties

   Не должно получиться лишнего уровня вида:
   midnight-android/Midnight_Android/app/...

3. Открой вкладку Actions.

4. Слева выбери:
   Build Midnight APK

5. Нажми:
   Run workflow -> Run workflow

6. Дождись зелёной галочки.

7. Открой завершившийся запуск.
   Внизу страницы будет раздел Artifacts.

8. Скачай:
   Midnight-APK

9. GitHub скачает ZIP. Внутри него будет:
   Midnight.apk

10. Передай Midnight.apk на телефон и установи.
    Если Android спросит разрешение на установку из этого источника — разреши его для приложения, через которое открываешь APK.

ЧТО ДЕЛАЕТ GITHUB
-----------------
Workflow автоматически:
- ставит Java 17;
- ставит Gradle 8.9;
- устанавливает Android SDK API 35;
- устанавливает Build Tools 35.0.0;
- выполняет :app:assembleDebug;
- переименовывает app-debug.apk в Midnight.apk;
- прикладывает его как Artifact.

Workflow находится здесь:
.github/workflows/build-apk.yml

СЕРВЕР MIDNIGHT
---------------

ЕСЛИ ACTIONS ПОКАЗЫВАЕТ КРАСНУЮ ОШИБКУ
--------------------------------------
Открой упавший запуск -> Build Android APK -> красный шаг.
Скопируй текст ошибки или пришли скриншот ChatGPT.
Не нужно заново настраивать Android Studio на Windows.

Примечание: сейчас собирается debug APK для тестирования на твоём телефоне.
Для публикации в Google Play позже сделаем отдельную release-сборку с подписью.
