MIDNIGHT ANDROID 1.0 — native client source

Это не WebView. Клиент использует API Midnight напрямую.
Реализовано:
- вход в существующий аккаунт Midnight;
- адрес сервера можно менять на экране входа;
- собственные и публичные треки;
- альбомы и публичные альбомы;
- исполнители и публичные группы;
- локальный поиск по медиатеке;
- загрузка аудиофайла с телефона;
- фоновое воспроизведение;
- уведомление с Назад / Play-Pause / Далее;
- MediaSession для экрана блокировки;
- очередь воспроизведения.

ВАЖНО
Текущий сервер пользователя работает по HTTP. В приложении cleartext HTTP разрешен для этой частной установки. Для публичной эксплуатации лучше включить HTTPS на Midnight и затем запретить cleartext.

СБОРКА
В этой среде Android SDK отсутствует, поэтому APK здесь не скомпилирован.
Открой папку Midnight_Android в Android Studio (JDK 17+), дождись Gradle Sync и выбери:
Build -> Build APK(s).
APK появится в app/build/outputs/apk/debug/app-debug.apk

compileSdk/targetSdk: 35
minSdk: 26 (Android 8.0+)
